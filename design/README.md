# Design files

- `source/` holds the native, editable files: FreeCAD, Fusion 360, SketchUp, Revit,
  KiCad, OpenSCAD. This is what makes the project open.
- `exports/` holds neutral formats anyone can open: STEP (3D), DXF or SVG (2D cutting),
  PDF (drawings), STL (3D printing).

Re-export whenever you change a source file, so the two stay in sync.
