# DirectPV TES Project Journal

### October 16 2026

I'm adding this project to github for the first time and trying to gather all my information. Here are some notes regarding the project history to date.

I built the system in 2024 at first without optimizing the array configuration for the heating element, and got only about 150w delivered to the heating element. This helped, but took a long time to heat up the tank. 

The next winter I did the calc on what voltage/amperage the element "wanted", reconfigured the array, and got about 450w. Much better! The tank heats up in a couple of hours, and I had to start putting a jacket on it during the day otherwise it'd cook me out of my studio. 

The relay never worked. Not sure if it came DOA or what. The temperature controller seems to function correctly, but I think I need a better/not broken relay. 

So currently I control the system at the breaker box mounted under the panels. This isn't safe, if I forgot about it I could cook my water off and melt stuff/cause a fire.
